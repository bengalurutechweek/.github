# Contributing

Thank you for wanting to help Bengaluru Tech Week.

The public repositories in this organisation are primarily visitor-facing resources. For programme questions or to report a website problem, email [hello@bengalurutechweek.com](mailto:hello@bengalurutechweek.com).

If a public repository accepts contributions, follow its own README and contribution notes. Keep reports focused, do not include personal attendee information, and disclose security concerns privately through [SECURITY.md](SECURITY.md).
