# Contributing

Thank you for wanting to help Bengaluru Tech Week.

Most programme participation happens through the official website rather than through public code contributions:

- Propose an event at [bengalurutechweek.com/host](https://bengalurutechweek.com/host).
- Volunteer at [bengalurutechweek.com/volunteer](https://bengalurutechweek.com/volunteer).
- Explore partnership options at [bengalurutechweek.com/partners](https://bengalurutechweek.com/partners).
- Report a website problem at [hello@bengalurutechweek.com](mailto:hello@bengalurutechweek.com).

Repository access is managed by the Bengaluru Tech Week team. Team members should use a focused branch, keep pull requests small, document validation performed, and never commit credentials, attendee data, private partner terms, or local machine paths.
