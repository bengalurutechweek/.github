# Security Policy

## Reporting A Vulnerability

Please report suspected security or privacy issues privately to [hello@bengalurutechweek.com](mailto:hello@bengalurutechweek.com) with the subject **Security report**.

Include the affected URL or repository, a clear description, reproduction steps when safe, and the potential impact. Do not include real attendee data, credentials, access tokens, or other sensitive material in a public GitHub issue.

We will acknowledge the report, assess its severity, and coordinate remediation. Please allow the team reasonable time to investigate before public disclosure.

## Scope

The policy covers Bengaluru Tech Week websites and services under `bengalurutechweek.com`, including the public website and link shortener.
