# Code Of Conduct

Bengaluru Tech Week is committed to a respectful, welcoming, and safe experience across its events, online spaces, and contributor interactions.

Everyone participating in Bengaluru Tech Week is expected to follow the current [Bengaluru Tech Week Code of Conduct](https://bengalurutechweek.com/code-of-conduct).

Questions or confidential incident reports can be sent to [hello@bengalurutechweek.com](mailto:hello@bengalurutechweek.com).
